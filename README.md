# 📄 個人簡歷網頁

一個現代化、功能豐富的個人簡歷網頁，純 HTML/CSS/JavaScript 實作，無需任何框架或後端。

🔗 **線上預覽**: [https://ga719061.github.io/resume-website/](https://ga719061.github.io/resume-website/)

---

## ✨ 功能特點

### 🎨 多主題切換
- **4 款預設主題**：深色霓虹、淺色簡約、藍色專業、紫色夢幻
- **自訂顏色**：可自由調整主色調與強調色
- 主題設定會自動儲存

### ✏️ 即時編輯模式
- 直接在頁面上點擊編輯所有內容
- 支援編輯：姓名、職稱、聯絡資訊、工作經歷、教育背景、技能、專案等
- 可新增/刪除列表項目（工作經歷、教育背景等）
- 可上傳自訂頭像

### 📦 板塊管理系統
- **新增板塊**：10 種預設板塊類型可選
  - 👤 關於我
  - 💼 工作經歷
  - 🎓 教育背景
  - ⚡ 技能專長
  - 🚀 專案作品
  - 📊 統計數據
  - 📝 自訂區塊
  - 🏆 證書認證
  - 🌍 語言能力
  - 💡 興趣愛好
- **刪除板塊**：編輯模式下可刪除不需要的板塊

### 💾 資料持久化
- 自動儲存至 `localStorage`，重開頁面不會遺失
- 支援 JSON 格式匯出/匯入備份

### 📤 多種輸出方式
- **🖨️ 輸出 PDF**：A4 紙張優化版面，一鍵列印為 PDF
- **🌐 輸出網頁**：匯出完整獨立 HTML 檔案，可直接分享給他人查看

### ✨ 視覺效果
- 粒子背景動畫
- 打字機文字效果
- 卡片 hover 上浮動畫
- 滾動漸入動畫
- 技能條動畫
- 計數器動畫

## 📝 使用說明

### 基本操作
1. **開啟設定** - 點擊右上角 ⚙️ 齒輪圖示
2. **切換主題** - 在主題區塊選擇喜歡的主題
3. **編輯內容** - 點擊「📝 編輯模式」，再點擊任何文字即可編輯

### 編輯模式功能
- 點擊文字直接編輯
- 虛線框表示可編輯區域
- 紅色 ✕ 按鈕用於刪除項目
- 「+」按鈕用於新增項目
- 點擊頭像可更換照片

### 資料管理
- **匯出資料**：點擊「📤 匯出資料」下載 JSON 備份
- **匯入資料**：點擊「📥 匯入資料」還原備份
- 資料會自動儲存，無需手動儲存

### 輸出分享
- **輸出 PDF**：點擊「🖨️ 輸出 PDF」→ 選擇另存為 PDF
- **輸出網頁**：點擊「🌐 輸出網頁」下載獨立 HTML 檔案
