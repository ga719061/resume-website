# 個人簡歷網頁

一個現代化、可編輯的個人簡歷網頁，純 HTML/CSS/JavaScript 實作，無需任何框架或後端。

## ✨ 功能特點

- 🎨 **多主題切換** - 4 款預設主題 + 自訂顏色
- ✏️ **即時編輯** - 直接在頁面上編輯所有內容
- 💾 **自動儲存** - 資料存於 localStorage，重開頁面不會遺失
- 📤 **匯出/匯入** - JSON 格式備份與還原
- 🖨️ **PDF 輸出** - 一鍵列印為 PDF
- ✨ **動態效果** - 粒子背景、打字機效果、3D 卡片

## 🚀 快速開始

1. 下載或 clone 此專案
2. 直接開啟 `index.html` 即可使用

## 📁 檔案結構

```
resume-website/
├── index.html   # 主頁面
├── style.css    # 樣式與主題
├── app.js       # 互動邏輯
└── README.md    # 說明文件
```

## 🎨 主題

| 主題 | 風格 |
|------|------|
| 🌙 深色霓虹 | 預設，霓虹漸層風格 |
| ☀️ 淺色簡約 | 明亮乾淨 |
| 💼 藍色專業 | 商務風格 |
| 🔮 紫色夢幻 | 紫色霓虹 |

## 📝 使用說明

1. **切換主題** - 右上角 ⚙️ → 選擇主題
2. **編輯內容** - 右上角 ⚙️ → 📝 編輯模式 → 點擊任何文字即可編輯
3. **備份資料** - 右上角 ⚙️ → 📤 匯出資料
4. **輸出 PDF** - 右上角 ⚙️ → 🖨️ 輸出 PDF
